# Historical ACU design

These documents preserve the original infrastructure proposal. They were not implemented
and do not define SCU's configuration format or supported commands.

- [CLI roadmap](ROADMAP.md): proposed editing, validation, conversion, and graph commands.
- [Resource types](resource-types.md): candidate resource vocabulary and suggested defaults.
- [Infrastructure example](infra.example.yml): proposed resource, connection, and scope graph.

Development continues in [SCU](https://github.com/carlosferreyra/scu), which has its own
design and implementation plan. These proposals remain here for reference without imposing
ACU's YAML format or planned feature set on SCU.
